# Nadeem Ahmed Ghoto — Portfolio Website

> Personal portfolio website — built from scratch, version by version.

**Status:** 🚧 In Development — Phase 0 (Foundation)

---

## About This Project

A modern, full-stack portfolio website built with **Python, Flask, HTML, CSS, and JavaScript**. Designed to showcase my work as an **AI/ML student** and serve as a long-term professional asset.

The project is being developed following a proper software engineering process:
requirements → design → coding → testing → deployment.

Full documentation lives in the [`docs/`](./docs) folder.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Backend | Python, Flask |
| Frontend | HTML5, CSS3, JavaScript |
| Database | SQLite (dev) → PostgreSQL (production) |
| Templating | Jinja2 |
| Deployment | Render |
| Version Control | Git, GitHub |
